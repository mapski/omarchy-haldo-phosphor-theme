# Workstation settings in progress

The first public build establishes the theme; workstation refinement continues.

## Selected defaults

- Phosphor Studio: warm green, ivory text, ink surfaces, Claude Code orange and magenta details.
- Codex and Claude equally, one native Agents widget, two named menu entries.
- Centered AM/PM clock and enabled native update indicator.
- Preserve existing third-party/custom widget sections, relative order and settings.
- Explicit optional profile application with private backups; retain current
  agent credentials, default agent, idle policy and monitor setup.

## Still available to work through

- Per-plugin placement and bar density, especially workspace and media widgets.
- Font family and text scale, including terminals and high-DPI displays.
- Window gaps, borders, opacity and focus treatment.
- Notifications, DND, and which agent events can actually signal attention.
- Static wallpaper versus optional existing Matrix Rain.
- Launcher grouping, shortcuts and project/workspace conventions.
- Optional weather, Bluetooth, display, Tailscale and resource widgets.

These are discussion items, not pending changes that the theme applies silently.

## Wallpaper and submission review — 2026-10-22

- User rejected the contour wallpaper and selected the original three image
  concepts: Jade Prism (default), Ember Coast and Phosphor Bloom. Final assets
  are 3840×2160 exports from 1672×941 generated images; preserve the original compositions and slightly increase
  Claude Code orange illumination and its soft glow. Later prism variants were
  rejected. Original 1672×941 sources are preserved in the parent project at
  `assets/wallpaper-sources/`; these preserve the source images. Existing desktop
  captures must be refreshed after final asset production.
- Finished wallpaper assets are sufficient. The generator is an authoring tool,
  not an installation requirement; no script removal or relocation has occurred.
- Omarchy scales to cover each screen with aspect ratio preserved and crops
  when the screen aspect ratio differs.
- Follow the [official gallery criteria](https://github.com/omacom/omarchy-site#adding-your-theme).
  The gallery screenshot dimensions are separate from wallpaper resolution.
- Durable project memory: [bot-memory, phosphor-studio branch](https://github.com/mapski/bot-memory/blob/phosphor-studio/projects/phosphor-studio.md).

## Approved orange refinement

- User-supplied Oranges reference: Claude Code orange `#D97757`, replacing
  amber `#D9AE6A` for the orange role, notification countdown and signal contour.
- Ivory foreground and green primary accent remain. Ethereal peach `#FFCEAD`
  was the previous desktop foreground, not the Phosphor foreground.
- Selection surface deepened from `#223027` to `#212E26` to retain at least
  4.5:1 contrast for the exact orange.
- User approved Claude Code orange with ivory text and green accents.
- Orange palette approved for application/publication. Earlier runtime screenshots
  are explicitly marked as historical.

## Theme application scope

The user authorized applying and publishing the theme. This applies colors and
three static backgrounds, defaulting to Jade Prism. The optional workstation
profile remains unapplied while its bar layout and other options are reviewed.
